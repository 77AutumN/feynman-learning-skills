# 费曼带读与因果知识卡

这个 skill 先负责把一个机制讲懂，再把同一因果整理成知识卡。现场教学不是成册流水线的预演；用户直接要求整理既有概念系列时，该请求本身构成收口指令。

尚未安装时，可以让 Agent 直接读取本文件并按当前请求执行。首次使用先给材料、一个想弄懂的问题和笔记保存位置；未指定位置时使用当前工作区的 `content/learning-notes/`。公开仓库中的 `examples/cache-hit/` 提供完整演示，演示问答不能充当当前用户的理解确认。生成内容仍需由用户核对，尤其是来源、公式与适用边界。

## 教学内核

一节只回答一个具体问题，一轮只给一个可感知的胜利。**“有什么、怎么运作、怎么证明”是三种不同的问题**；即使属于同一主题，也不能塞进同一轮。用**一镜到底**跟随一个真实对象：先让用户看见它的起点，再展示真正改变、辨认或检验它的动作，最后停在能回答开场问题的证据。对象和动作看得见以后，再贴技术术语、源码或公式。

各类概念与论文带读默认用日常语言、小步推进，并保留每小步一个可跳过的问题。理解深度靠讲清来由、真实步骤与成立条件，再从用户对新条件的推理中检查；涉及方案改进时，还要讲清收益与实际代价。这些内容分轮展开，不用一轮的术语数量衡量深度。

现场带读先显示**阅读状态条**守住本节主线；首次开讲再用**生活镜头**让关系或机制发生并映射回技术对象。首次解释与整体重讲必须通过 `reference/live-reading.md` 的**冷启动门**；未通过时重写开场并保持当前站点。三类问题的主镜头、机制来由、逐步深化、互动反馈与写回规则以该文件为准。

- 用用户已经会的词和本节真实例子讲，不把内部流程名词说给用户。
- 形象来自可见的因果变化；比喻只在准确时使用，不用热闹替代机制。
- 具体版本、路径、数值、源码和运行结果必须来自已经读取的材料或实际检查；没有证据时明确写成假设例子，不把合理猜测说成当前事实。
- 可以预先检查多项事实，但用户可见的这一轮只保留回答当前问题所需的证据；环境清单、机制解释和正确性验收分别讲。
- 普通带读直接开讲，不先考试，也不要求用户复述。用户主动要求逐题检查时，每轮只检查一个问题，等其回答后再继续。
- `讲过 ≠ 学会`。用户说“继续”只表示继续教学；只有明确说“懂了、收口、整理、做卡片”等才进入成册。
- 系列 `index.md` 是进度与 episode 的唯一事实源。聊天记录、全局 HTML、历史账本都不能另建一套状态。

状态契约始终不变：只使用 `待学 → 学习中 → 已闭环`；中断、重讲、返修和渲染重试都复用当前 episode ID。`已闭环` 需要用户理解确认、自测、已验收卡片及其导演单证据、索引链接与下一入口四项证据，索引必须最后更新。存在父子索引时，子索引拥有当前小节状态，父索引只负责路由。

收口请求授权制作产物，不自动证明用户理解。没有真实理解确认时可交付知识卡和待答自测，但状态保持 `学习中`；不得用模拟问答、复制的历史回答或运行验证填补这一项证据。

## 先判分支，再加载

### 1. 开始或继续带读

完整读取 `reference/live-reading.md`。

- **继续现有系列**：先从该系列 `index.md` 定位有效系列覆盖、当前 episode、范围、阅读条、卡点和下一入口；历史归档、旧实验、完整路线和旧导演单只在当前问题需要时读取。正常续读不加载 `reference/series-state.md`。
- **新建系列，或需要创建、修复、切换、收窄、写回 episode 状态**：再完整读取 `reference/series-state.md` 后操作；阅读状态条的常规位置写回按 `reference/live-reading.md` 直接执行。

随后在同一轮直接讲一个完整的小因果单元。此分支不加载成册或渲染规则。

### 2. 用户说没听懂

读取 `reference/live-reading.md` 的“重讲”部分。先判断是一个可定位的黑箱，还是整条解释结构已经失败：前者原位放大一个动作；后者丢弃旧镜头，把问题缩小一级，换一个真实对象重讲。重讲不新增术语，不把讲解失败记成用户薄弱项。

若属于长期系列，同时读取当前 `index.md` 以守住本节边界；不要因此推进 episode 或进入成册。

### 3. 过程可视化

只有纯文字或小草图不足以让状态变化可见时，额外读取 `reference/process-visuals.md`。先做最小教学原型；HTML 是解释的载体，不是每节必交品。

### 4. 明确收口成册

只有用户明确确认理解或要求整理时，才完整读取：

- `reference/series-state.md`
- `reference/closeout.md`
- `reference/card-production.md`

再按需读取 `templates/visual-brief.md`、`templates/feynman-selftest.md` 和当前系列的 `cards/render_cards.py`。成册完成后停在下一节入口，不自动继续教学、发布或提交 Git。

既有概念系列中，“整理下一集”“直接出图”属于明确成册请求：从系列索引和既有证据恢复下一入口，直接进入本分支，不补做形式化带读。保留用户已选择的系列路径。固定英文源码的逐段中文映照不在本技能范围内；可以按已核实的源码讲清一个机制，但不生成完整源码映照系列。

知识卡使用随包的 `v0` 视觉基线，规则见 `reference/card-production.md` 的“视觉底座”。

## 路径

系列默认位于当前工作区的 `content/learning-notes/<series-slug>/`；新系列可采用用户指定的位置，已有系列继续使用原位置：

- `index.md`：当前进度与下一入口
- `figures/`：带读过程中真正有用的可视化
- `cards/`：视觉导演单、渲染器、PNG 与贴图页
- `NN-<title-slug>.md`：本集《费曼自测》

学习产物保持平实、准确，发布包装按用户另行提出的要求处理。制作笔记不包含发布或提交 Git 的授权。
