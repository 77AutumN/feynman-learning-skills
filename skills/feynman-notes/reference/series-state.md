# 系列状态

本文件只在创建、恢复或更新学习系列时加载。系列目录中的 `index.md` 是当前进度的唯一事实源；默认目录为当前工作区的 `content/learning-notes/<series-slug>/`，用户指定的位置优先。

## 新系列

教学开始前创建系列目录、`figures/` 和 `index.md`。首个 episode 使用 `01`，状态写为 `学习中`。索引至少保存：

- 系列名、slug、材料与来源；
- 当前 episode ID、当前路线节点和一个具体问题；
- 本节范围、明确不展开项与出口；
- 本节 3–6 个阅读站点、当前位置，以及可选支线与主线返回点；
- 状态、完成证据、用户真实卡点；
- 下次开场一句话、下一入口和续读口令。

材料跨多个节点时，可在同一索引维护节点与关系。沿用该系列已有的节点 ID 体系，例如 `A01`、`M02`；已经被引用的 ID 不重排。关系写清前置、组成、因果、对照、证据或应用，并区分来源事实与教学推断。

全局 HTML 只是索引的视觉派生物。只有它确实帮助定位时才创建，不因画地图延迟开讲。

## 续读

1. 先从当前系列 `index.md` 定位有效系列覆盖、当前 episode、范围、阅读条、卡点和下一入口；历史归档、旧实验、完整路线和旧导演单只在当前问题需要时读取。
2. 只在当前问题需要时，再读索引指向的来源段落、术语表、路线图或上一集薄弱项；历史账本不是默认必读。若当前问题依赖本机环境、源码、实验或测量值，先做安全的只读检查或读取已有快照，再陈述具体事实。
3. 从索引恢复阅读站点、当前位置和可选支线，先显示状态条；再用一句话恢复“已知上游 → 当前问题 → 解开后去哪”，随后直接继续教学。
4. 若索引把“盘点有什么、解释怎么运作、验证是否正确”或其他独立结果写在一起，把当前教学镜头收窄为一个问题，其余移入不展开项或下一入口，再开讲。一个 episode 可以跨多轮，但每轮仍只有一个胜利。

用户说“继续”不代表理解，也不触发整理。中断后仍复用当前 episode ID；不保存半节聊天流水账，已落盘且仍准确的辅助图可以复用。

## 状态与 episode

状态只使用：

`待学 → 学习中 → 已闭环`

- 真正开始教学时，把当前 episode 置为 `学习中`。
- 中断、重读、讲解返工、成册重试和渲染重试都沿用当前 ID。
- 只有当前 episode 已经 `已闭环`，才分配下一个 ID。不要通过扫描磁盘最高编号临时 `+1`。
- 一个路线节点可以跨多个 episode；路线节点 ID 与 episode ID 分开维护。

旧系列只在下一次真正续读时补齐当前问题和必要字段，不批量改写历史，也不回滚已完成集。

## 收口边界

“继续”只恢复教学；用户明确说没懂时继续当前 episode。普通带读不要求复述，用户没有复述也不是薄弱项。逐题检查只在用户本轮主动要求时采用。

用户明确说“这一节懂了、可以收口、整理笔记、做成卡片”时，停止使用本文件推进状态，转入 `closeout.md`。闭环证据、卡片生产与索引更新顺序只在收口分支执行。

## 父子索引

若存在总索引和子系列索引，子索引负责当前问题、状态、范围、证据与下一入口；父索引只负责子系列路由。两者冲突时以子索引为准。小节闭环只更新子索引，切换子系列时才更新父指针。
