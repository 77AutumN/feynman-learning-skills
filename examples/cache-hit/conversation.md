# 带读对话示例

以下对话是为演示流程编写的合成内容，不是真实用户记录，也不证明任何使用者已经理解。实际用法是让 Agent 读取 `source.md`，根据你的反馈逐步讲解。

**示例请求**：带我读 source.md，先讲为什么同一个输入第二次不用再算。

**示例讲解**：

> 本节：缓存命中怎样省掉重复计算
> 当前位置：第一次请求 → 保存结果 → 第二次请求 → 正确边界
>
> 想象你查了一次 3 的平方，把“3 对应 9”记在本子上。下次又有人问 3 的平方，你先翻本子，发现已有答案，直接把 9 告诉他。这次省掉的是重新计算的动作。程序做的是同一件事：先查结果表，查到才复用。
>
> 可跳过的小问题：第二次问 3 时，答案还是 9，真正的计算次数会增加吗？

**示例反馈**：继续。

**示例续讲**：

> 继续本节，还没有进入制卡。
>
> 现在换成问 4 的平方。表里只有“3 对应 9”，没有 4，所以得算出 16，再把“4 对应 16”记进去。查到了叫 cache hit（缓存命中），没查到叫 cache miss（缓存未命中）。两种情况都先查表，只有后者要做计算。

**示例收口请求**：这一节懂了，整理成知识卡和自测。

**示例成册动作**：保持 episode 01，先确定本节边界和分镜，再生成知识卡、自测与验收记录。实际学习时，用户确认与实际作答按事实记录；这里保留为演示模式，不把这句合成请求写成真人理解确认。

**示例精华请求**：把这一节完成的材料整理成 900 字以内精华。

示例短稿见 [essence.md](essence.md)。实际保存器会校验长度并创建新的 revision。
